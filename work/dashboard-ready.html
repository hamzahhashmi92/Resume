A ready signal for the live dashboard

The dashboard loads eight data sources at once. I made it announce on its root element when every one of them has rendered, and how long that took, so automated tests can start at exactly the right moment.

  • React hooks
  • CustomEvent
  • TanStack Query

The problem

One element appearing on screen doesn't mean the dashboard is ready: eight sources load independently, and tests need to know when all of them are in.

My part

  • A ready event for each of the eight sources, emitted once per session.
  • A waiter that also counts events fired before it subscribed, with full listener clean-up.
  • data-ready and data-ready-ms on the dashboard root, for tests and load-time tracking.
  • Flights loaded per calendar day with TanStack Query: today refreshes every 5 seconds, past days are fetched once and cached.
  • 10 test cases for early, late and repeated events.

Result

The dashboard reports when it is ready and how long that took, and switching back to a past day loads from cache instead of the network.

// child effects run before the parent subscribes,
// so remember what already fired
const fired = new Set();

export function emitReady(name) {
  if (fired.has(name)) return;
  fired.add(name);
  window.dispatchEvent(new CustomEvent(name));
}

export function waitForAll(names, onReady) {
  const pending = new Set(
    names.filter((n) => !fired.has(n)));
  const done = () => pending.size === 0 && onReady();
  const off = [...pending].map((name) => {
    const handler = () => { pending.delete(name); done(); };
    window.addEventListener(name, handler, { once: true });
    return () => window.removeEventListener(name, handler);
  });
  done();
  return () => off.forEach((f) => f());
}

// today polls every 5 s; past days are cached for good
useQuery({
  queryKey: ["dashboard flights", start, end, isPastDay],
  refetchInterval: isPastDay ? false : 5000,
  staleTime: isPastDay ? Infinity : 0,
});
