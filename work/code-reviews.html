Case 09 · AstraUTM platform

Code reviews

I reviewed 120 merge requests that went into the AstraUTM platform, and I run colleagues' changes locally before approving. Some of the issues I raised:

  • 120 merge requests
  • GitLab
  • SonarQube

Memory

Releasing temporary file links

A file viewer released its object URL on a 10-second timer. I asked for proper clean-up, so links neither leak nor disappear while the file is still open.

Translations

A consistent migration

During the move to Paraglide I flagged old translation hooks, leftover t() calls, keys that should be shared, and an altitude label that ignored the feet and metres setting.

Quality

Clean merges

Missing alt text on images (an accessibility and SonarQube warning), unused imports, a stray console call in a test, and conflicts left unresolved.

Tests

Stable selectors

I asked for test IDs instead of text or class selectors in a colleague's tests, and agreed a pattern for dashboard rows: a test ID plus the flight's ID as a data attribute.

Safety

Defensive data access

Safe access to nested API responses when saving an incident, and removal of hard-coded strings from user pages.

Verification

Checked locally

For changes with a wide reach I run the branch, check the dashboard and the other critical pages, and confirm the result in the review.
